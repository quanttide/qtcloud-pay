# dashboard 总览（M1 起）

客户端位置：`lib/screens/dashboard_screen.dart`、`lib/widgets/milestone_card.dart`

服务端对应：无独立 API，数据来自各模块查询 + 本地里程碑状态。

## 职责

管理人员入口页：里程碑状态（M1–M5）、今日待办（未对账 / 待结算）、快捷入口。不承载业务数据计算，仅聚合展示。

## 页面与组件

| 页面/组件 | 说明 |
|-----------|------|
| `dashboard_screen.dart` | 总览页：顶部里程碑状态卡 + 待办区（对账提醒、待结算订单）+ 快捷入口（充值登记/发券/下单/对账） |
| `MilestoneCard` | 里程碑状态卡：M1–M5 状态（⬜ 未开始 / 🚧 进行中 / ✅ 已完成）与验收结论 |

## 数据来源

| 待办项 | 数据来源 |
|--------|---------|
| 未对账 | `GET /reconcile/consistency`（差异数 > 0 时提醒） |
| 待结算 | 本地最近操作记录（v0.1.0 客户端不做轮询，联调阶段以手动刷新为准） |
| 里程碑状态 | 本地配置（对照[工作台 §一](../../../../../data/roadmap/studio.md) 手动更新） |

## 关键点

- 里程碑状态是管理人员手动维护的看板数据（对应工作台 §一 表格），客户端本地存储，不上报服务端
- 待办聚合只读调用服务端查询接口，不触发任何写操作
- 快捷入口跳转到对应页面（充值登记 / 发券 / 订单结算 / 对账），与各模块文档对应

## 测试

widget 测试：里程碑卡三种状态渲染、待办提醒（差异数>0）、快捷入口跳转。
